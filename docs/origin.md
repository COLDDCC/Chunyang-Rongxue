# 名字的来历：春阳融雪

## 一次从武侠谈起的产品构想

这个 Skill 的名字来自一次关于戊戟武侠小说《黑鹰传奇》的讨论。讨论从男主慕容智（痴儿）的武学天赋出发，逐渐谈到小说中被称作「春阳融雪功」的武功。

用户由此提出一个极具画面感的比喻：**把竞争对手的优点当作可以吸收的功力**。一个网站或小程序，可以从许多优秀产品身上学习不同长处，最终成为综合体验十分出色的作品。于是这个 Skill 被命名为 **春阳融雪**。

这段命名是创作故事，而不是在为小说武学作权威考据；小说情节的具体描述应以正式出版文本为准。这里借用的是「吸收并转化」的文学意象，而非照搬原作设定或受版权保护的表达。

## 从「吸取」到「融化」

真正让名字成立的，是紧接着的一次思想升级：

> 不能只是吸收别人的优点，更要让这些优点融会贯通，成为自己的能力。

比如：从一个产品学习克制的首屏，从另一个学习无阻力的交互，再从第三个学习清晰的解释方式和搜索可发现性。不能将三个页面粗糙拼接，而要重新设计一条自然、统一、独特的用户路径。

### 观、吸、化、创、验

- **观**：寻找高手，确定他们到底强在哪里。
- **吸**：提炼真正有价值、可迁移的机制。
- **化**：去掉冗余，吸收为自己的产品语言。
- **创**：针对用户真实需求做出新的突破。
- **验**：用数据、测试和实际操作检验结果。

## 六条戒律

多师制、去芜存菁、融会贯通、反向创新、数据验收、持续进化。

其中最关键的一条是：**春阳融雪必须学会拒绝。** 不因为对手有某项功能，我们就必然需要它；不因为某个网站精美，我们就牺牲自己的效率、可访问性或品牌辨识度。

## 这个名字希望留给未来的提醒

> 博采众长，去芜存菁，融会贯通，青出于蓝。

它不是「复制竞品」Skill，也不是「自动保证高分」的魔法。它是一种认真研究、善于提炼、敢于取舍、亲手验证的产品工作方法。
