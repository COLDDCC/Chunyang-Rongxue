# Case 02: content-page field run (real page, Draft mode)

A real run of this Skill on one public article:
https://saipanivf.pages.dev/guides/egg-freezing-cost/ (Chinese, cross-border fertility pricing guide),
on 2026-10-26, by an agent without repository access. Its lessons produced v1.2.0.

## Files
| File | What it is |
|---|---|
| `report.json` | Draft-mode, content-profile report: summary, business goal, 6 labelled estimates, 7 competitor advantages, roadmap |
| `report.md` | Generated by `scripts/render_report.py` (do not edit by hand) |
| `page.md` | The drafted replacement article (v3), *planned*, not deployed |

Scores in `report.json` describe the **original page** (baseline), observed by text extraction only.
Visual, performance and accessibility stay unscored: no screenshots or measurements were taken.

## What happened
1. **Observe.** Five competitors with distinct roles: GoodRx (answer-first content), TreatCompare
   (price comparison), HKU IVF (official fee table), NuwaCare (cross-border guide), MedPark
   (clinic package page). About half of the raw search results were SEO spam on unrelated domains
   and were discarded. This led to the source-quality rules in competitor discovery.
2. **Absorb.** The page under review was the only one whose figures were internally consistent and
   dated; two competitors contradicted their own figures. Copying competitors' success-rate claims
   and savings percentages was rejected.
3. **First draft (v1.1 rules).** The Skill steered the agent to *withhold* travel costs until
   verified. The site owner pointed out that such pages exist to start an offline conversation and
   readers need a reasonable range. That reasoning became rule 7 and the estimates reference.
4. **Second draft.** Added total trip budget, three tiers, days on site and local currency. While
   writing it the agent introduced a drift: the answer card said US$15,600–22,600 while the tier
   table summed to 15,500–22,950. It was caught by hand. `scripts/check_numbers.py` now catches
   it automatically (`tests/test_check_numbers.py`).
5. **Third draft (v1.2 rules).** Every estimate lists basis and date; one data note replaces repeated
   disclaimers; the CTA asks for a concrete action right after the tier table; FAQ items that
   duplicated the body were replaced by unanswered questions.
