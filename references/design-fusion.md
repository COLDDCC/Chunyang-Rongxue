# Coherent design fusion · 化 / 创

## Synthesis checklist
1. State the principal user job in one sentence.
2. Draw the fastest path from entry to successful outcome.
3. Reconcile discovered patterns into shared typography, spacing, color semantics, components, iconography, and keyboard/touch behavior.
4. Above the fold: answer first / primary action first; add explanatory text only when it clarifies a decision or meets true search intent.
5. Turn repeated information into useful tables, filters, comparison cards or visualizations **when these make decisions easier**. Do not decorate with fake controls.
6. Keep localization native, currency/pricing correct, and locale routes/canonicals/hreflang coherent.
7. Consider mobile, slow network, reduced-motion, contrast, focus and screen readers.
8. Protect the existing differentiators and establish a rollback path.

## Innovation criterion
State at least one opportunity where we could improve the original user outcome rather than merely imitate a rival. Label it a hypothesis until tested. Use impact × confidence ÷ effort to prioritize if no richer evidence exists.

## Anti-patterns
- Five competitors' aesthetics pasted together.
- Lengthy keyword-stuffed SEO blocks masking a weak tool.
- Artificial scores implying objectivity.
- Arbitrary animation, text clutter, dead buttons, misleading testimonials.
- Treating features as value regardless of real use.
